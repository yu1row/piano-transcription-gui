# Piano Transcription GUI 説明書

バージョンはアプリ起動時のタイトル、または version.py を参照してください。

## 概要

本アプリは ByteDance のピアノ書き起こし研究実装（piano_transcription_inference）を使い、ローカル環境でピアノ音源を MIDI に変換します。

- ライセンス: Apache License 2.0（詳細は LICENSE / NOTICE）
- 対応入力: wav / mp3 / flac / ogg / m4a など
- 出力: Standard MIDI File (.mid)

## 使い方

1. **入力オーディオ**でピアノ録音を選択します。
2. 必要なら **出力 MIDI** の保存先を指定します。
3. パラメータを調整するか、**音源から自動設定**を押します。迷ったら **デフォルトに戻す** も使えます。
4. 必要に応じてプレビュー欄で短い区間を変換・再生して確認します。
5. **MIDI に変換**でフル変換を実行します。

初回実行時は事前学習モデル（約 165 MB）を自動ダウンロードします。

## パラメータ

| 項目 | 意味 |
|------|------|
| デバイス | auto / cuda / cpu。CUDA が使えるなら GPU が高速です。 |
| バッチサイズ | 同時処理セグメント数。通常は 1。 |
| セグメント長 | 分割推論の長さ（秒）。長いほど境界が減りますがメモリが増えます。 |
| Onset 閾値 | ノート開始の検出感度。上げると厳しく、下げると敏感。 |
| Offset 閾値 | ノート終了の検出感度。 |
| Frame 閾値 | 各時刻で音が鳴っているかの判定。 |
| Pedal offset 閾値 | サスティンペダル終了の判定。 |
| チェックポイント | モデル重み (.pth)。未配置なら自動取得。 |
| ゴーストノート削除 | 短い／弱い／同音の近接重複ノートを MIDI 書き出し前に除去。 |

論文・公式実装では onset / offset / frame / pedal の目安はおおよそ 0.3 / 0.3 / 0.1 / 0.2 です。

ゴースト除去の目安は最短長 30 ms、最小ベロシティ 8、同音マージ 30 ms です。スタッカートを残したい場合は最短長を下げてください。

## 音源からの自動設定

冒頭数十秒を解析し、次の特徴から閾値を調整します。

- 平均音量（RMS）
- オンセット密度（単位時間あたりの立ち上がり）
- スペクトルの平坦さ（ノイズ・残響っぽさ）
- ダイナミクス（ピークと RMS の比）

推定結果はあくまで初期値です。プレビューで確認してからフル変換してください。

## プレビュー再生

プレビュー欄で開始位置と長さを指定し、「区間を変換して再生」で短い MIDI を作って簡易合成音で聴きます。パラメータ比較や失敗調査に使います。ノートが 0 件の場合は無音になります。

## トラブルシューティング

### librosa.core.audio 関連エラー

新しい librosa では上流パッケージ同梱の load_audio が動かないことがあります。本アプリは独自ローダ（audio_io.py）で回避しています。最新版を使ってください。

### mp3 が読めない

ffmpeg をインストールし PATH を通すか、配布 zip 同梱の ffmpeg.exe を利用してください。

### CUDA が使えない

配布 exe は CPU 版 PyTorch を想定しています。GPU を使う場合はソース実行で CUDA 版 torch を入れてください。

### 変換が遅い / メモリ不足

セグメント長を短くする、バッチサイズを 1 のままにする、CPU ではなく GPU を使う、を検討してください。
